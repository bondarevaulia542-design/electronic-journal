❓ Помощь по работе с программой

📂 Загрузка файла

Что здесь происходит? Вы можете загрузить данные из файла.

  • Выберите файл на компьютере
  • Нажмите кнопку "Загрузить"
  • Данные автоматически отобразятся в таблице

✏️ Редактирование

Что здесь происходит? Вы можете добавлять, изменять или удалять записи об учениках.

  • Добавление: Заполните форму и нажмите "Добавить"
  • Редактирование: Введите номер строки, измените данные и нажмите "Редактировать"
  • Удаление: Введите номер строки и нажмите "Удалить"
  • Быстрые действия: В таблице есть кнопки ✏️ (редактировать) и 🗑️ (удалить)
  • Сохранение: Можно сохранить данные в CSV или Excel файл

📊 Статистика (таблица)

Что здесь происходит? Отображается подробная статистика успеваемости в виде таблиц.

  • По каждому классу: Средняя оценка, медиана, распределение оценок (2,3,4,5) по каждому предмету
  • Общая статистика: Те же показатели по всем классам вместе
  • Данные представлены в процентах для наглядности
  • Нажмите "Обновить статистику" для актуализации данных

📈 Статистика (графики)

Что здесь происходит? Те же статистические данные, но в визуальном формате — столбчатые графики.

  • Графики по классам: Для каждого класса отдельно показано распределение оценок по предметам
  • Общие графики: Распределение оценок по всем классам вместе
  • Высота столбцов показывает количество оценок
  • Под каждым графиком указаны средняя оценка и медиана
  • Нажмите "Обновить графики" для пересчета
